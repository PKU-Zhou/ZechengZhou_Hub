# 核心概念辨析

## 软件视角

![[Drawing 2026-11-04 13.23.24.svg]]

| 层级     | 解析                     |
| ------ | ---------------------- |
| Thread | 线程                     |
| Warp   | 线程束，固定32个thread为1个warp |
| Block  | 若干个warp组成一个block       |
| Grid   | 若干个block组成一个grid       |
实际上，warp这一概念是由硬件一侧带来的。

最优雅的层级概念为：***==🔴thread-->block-->grid==***
其中，block和grid都可以是多维的。


```python
# 某一线程的序号 = 其在当前block中的编号 + 当前block的编号*每个block中的线程数
int tid = threadIdx.x + blockIdx.x * blockDim.x;
```


很多时候了解到warp这一层级，对写出更高效的代码有帮助，所以这里也介绍了warp的概念。
类似的，还有block cluster的概念。


## 软件到硬件
软件侧编写核函数（kernel），kernel会编排好每个thread的任务。
硬件侧CPU将kernel（整个grid）发送给GPU，GPU以block为单位，安排计算任务到SM中执行。

![[Excalidraw/Drawing 2026-11-04 14.00.38.svg]]
这里就可以看到，为什么warp的概念如此重要。
因为SM内部的warp scheduler就是以32个线程为单位进行调度的。

## 硬件视角
CPU+GPU的系统示意图

![[Pasted image 20261104134823.png|522]]



GPU的核心是SM（streaming multiprocesor），如果强行分出层级概念的话，大致如下：

![[Excalidraw/Drawing 2026-11-04 14.26.48.svg]]

| 层级             | 解析                                 |
| -------------- | ---------------------------------- |
| GPU            | Graphics Processing Unit，图形处理器     |
| GPC            | Graphics Processing Cluster，图形处理集群 |
| TPC            | Texture Processing Cluster，纹理处理集群  |
| SM             | Streaming Multiprocessor，流式多处理器    |
| SMSP/partition | SM Subpartition,SM 子分区             |
每个子分区中还可以分出三个主要部分：

| 名称             | 解析                                                    |
| -------------- | ----------------------------------------------------- |
| Execution Unit | 执行单元，包括 **CUDA Core**（CUDA 核心）、**Tensor Core**（张量核心）等 |
| Register File  | 寄存器组，RF                                               |
| Warp Scheduler | 线程束调度器                                                |

从存储的层级也能看出来，SM是最重要的核心概念，GPU到SM中间的层级完全不重要。
