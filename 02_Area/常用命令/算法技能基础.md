## hugging face

1. 优先走国内镜像。
```bash
HF_ENDPOINT=https://hf-mirror.com
```

2. 如果下载速度慢，可能是因为走了Xet，可以考虑该走普通HTTP
```text
hf-mirror.com（镜像入口）

↓ Xet 下载机制

us.aws.cdn.hf.co（官方对象存储/CDN）
```

3. 登录hf可以获得更快的速度：
```bash
hf auth login
# 然后输入hf网站，个人设置中的access token
```

## 安装flash-attention
```text
目前官方 FlashAttention 最新版本为 `2.8.3.post2`，其预编译 wheel 最高提供到 PyTorch 2.8，没有适配你当前的 Python 3.13 + PyTorch 2.15 + CUDA 13.2 的 wheel。
```

### 第1步
创建单独的conda环境
```shell
conda create -n qwen-vl python=3.12 pip -y
conda activate qwen-vl
```
创建完成后，确认一下python版本：
```shell
which python

python --version

python -m pip --version
```



## 下载pytorch包
优先使用镜像
```shell
python -m pip install torch==2.8.0 \
  --index-url https://mirror.sjtu.edu.cn/pytorch-wheels/cu129 \
  --extra-index-url https://mirrors.aliyun.com/pypi/simple/
```
