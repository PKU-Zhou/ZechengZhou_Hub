# .lib转.db

在lib文件所在的路径下，运行该脚本：

```tcl
set lib_dir "./"

foreach lib [glob $lib_dir/*.lib] {
    read_lib $lib
    set lib_name ""
    set lib_name [get_object_name [get_libs]]
    write_lib $lib_name -format db -output ./$lib_name.db
    remove_lib -all
}
```
